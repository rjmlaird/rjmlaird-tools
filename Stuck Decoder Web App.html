Modular Logic breakdown

  • lib/storage.ts: Manages current task session, draft input auto-saving, and completed/saved list persistence.
  • lib/heuristics.ts: Deterministic keyword taxonomy parser for 8 domain categories (Email, Admin, Cleaning, Writing, Coding, Research, Call, General).
  • lib/rules.ts: Local rulebook holding 35+ physical, sub-10-minute interventions mapped by barrier and domain.
  • lib/actions.ts: Single-page reactive UI router & Web Audio synth for ambient chime feedback.

Deferred V2 Roadmap (Intentionally Excluded from MVP)

To preserve speed, privacy, and zero cognitive friction, the following features are deferred:

  • AI LLM assistance or cloud-based text generation
  • Voice dictation capture & audio processing
  • Energy/chronotype-aware contextual scheduling
  • Calendar / Google Workspace integrations
  • Live peer body doubling / social rooms
  • Data sync, account auth & cloud export
